# Cashfree sandbox only
Disabled by default. No live endpoint, real money, production checkout or refund support. Only authenticated staff on the base fictional restaurant may initiate a test checkout; isolated visitor demos cannot use the gateway.
Configure sandbox credentials and a sandbox test phone, HTTPS APP_URL, CASHFREE_ENV=sandbox, ENABLE_CASHFREE_SANDBOX=1 only after review. Set webhook to /api/payments/cashfree/webhook in the sandbox dashboard. Never enter live credentials. Test using official test instruments only.
Merchant ID derives from invoice UUID; amount is server calculated; manual payment is blocked once checkout starts. A signed webhook triggers independent Get Order confirmation; status, amount, currency and ID must match before the separate sandbox record is verified. The receipt distinguishes sandbox from manual demo payment. Sandbox records are not real revenue and are not included in the manual payment report. Gateway expiry/cancel/retry recovery, refunds, complete reconciliation and a real sandbox API exercise remain pending.
